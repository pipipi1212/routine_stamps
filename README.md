# DAYTRACE

毎日の登校、勉強、課題を記録し、小さな達成をスタンプで集めるローカルファーストのiPhone向けWebアプリです。Vanilla JavaScriptとIndexedDBを使い、アカウントやバックエンドは必要ありません。

## 起動

ES modules、IndexedDB、Service Workerを使うため、プロジェクトのルートでローカルHTTPサーバーを起動してブラウザで開きます。

```powershell
node serve.mjs
```

PCでは `http://localhost:8000` を開きます。iPhone Safariで位置情報を使う場合はHTTPSで配信してください（localhost以外のHTTPでは位置情報を利用できません）。静的ファイルをHTTPS対応の静的ホスティングへ置けば利用できます。ホーム画面へ追加するとスタンドアロン表示できます。

## 機能

- ホーム、日別計画、登校チェックイン、課題管理、勉強タイマー、コレクション、振り返り、設定
- IndexedDBに計画、チェックイン、課題、勉強セッション、週間目標、スタンプと獲得履歴、設定を保存
- JSTの期限判定、GPS距離判定、日次・週次の勉強集計、スタンプの重複防止
- JSONバックアップの書き出しと復元（復元時は既存データを置換）
- キャッシュ済み静的ファイルによるオフライン起動の補助

## データとプライバシー

行動履歴や位置情報はブラウザのIndexedDB内に保存し、外部サーバーへ送信しません。位置情報はチェックイン操作時だけ取得します。端末の現在日時を期限判定に使うため、端末時計の変更は検知できません。ブラウザデータを消去すると記録が失われるため、定期的に設定画面からバックアップしてください。バックアップJSONにも位置情報が含まれる場合があります。

データは端末とブラウザごとに独立し、自動同期はありません。Safariのプライベートブラウズなど、ストレージを保持しない環境では継続利用に制約があります。静的ファイルの更新時は、`sw.js` のキャッシュ名を更新してください。
